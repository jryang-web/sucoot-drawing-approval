# sucoot-drawing-approval
SUCOOT 圖面申請、雙層審核與 LINE 通知管理系統（V5.9.2，**測試版**）

## V5.9.2 版本說明：案件結果通知

- 工作首頁新增「案件通知」（已讀／未讀、最近 30 天），並同時發送手機推播（需已啟用通知）：
  - **駁回** → 申請人、負責人
  - **管理員強制結案** → 申請人、負責人
  - **申請人取消** → 原本待審的主管（含有效代理人）
  - **簽收完成** → 發行該案的圖管人員
- 推播只顯示通知類別摘要（例如「有 1 則『申請已駁回』通知」），不顯示案件編號；App 內通知可看到案件編號並開啟案件。
- 角標＝未讀安全通知＋未讀案件通知＋待辦案件；標為已讀後角標下降。操作者本人不會收到自己操作的通知。

## V5.9.1 版本說明：App 角標與背景通知

- **角標＝未讀通知＋待辦案件**：工作首頁「通知與角標」與左側「工作首頁」旁的數字，顯示目前帳號的未讀安全通知與待辦案件（同一案件只算一次）。支援的手機／電腦會同步顯示在 App 圖示上；不支援時以頁面數字為準。
- **同步時機**：登入、開啟 App、回到前景、恢復連線、完成案件操作、通知標記已讀、切換到工作首頁、收到推播。離線時標示資料時間，不當成即時資料。
- **背景通知**：系統管理員完成推播設定前，工作首頁顯示「背景通知尚未開放」。開放後，按「啟用通知」才詢問權限。有新的待辦（第一層／第二層待審、退回補件、待發行、待簽收、整案異常）時，只通知有權處理的人；通知內容不含案件編號、申請人或產品資料。iPhone 需 iOS 16.4 以上、加入主畫面並從主畫面開啟、允許通知並開啟「標記」。
- **登出**：清除角標並停用此裝置在該帳號的通知。
- 雙層審核流程、帳號角色、產品搜尋、LINE 測試模式（Mock）均不變。發布方式見 `docs/release-v591.md`。
- **Windows 本機預覽**：在專案資料夾雙擊 `本機預覽.cmd`（需要 Node.js 與 `.env.local`），會自動安裝套件、建置（同時檢查 `.env.local` 是否為正確的 Supabase 專案）並開啟瀏覽器。注意：本機 `npm run dev` 需要 Linux＋Docker 本機後端，在 Windows 無法登入；請改用此預覽。預覽連線正式資料庫，登入後請只檢視。

## V5.9 版本說明：產品智慧搜尋與 Excel 主檔同步

- **新增申請**：每筆產品可「搜尋產品」，輸入產品編碼、品名或規格的部分文字（可用空白分隔多個關鍵字），點選後自動帶入產品編碼與「品名 / 規格」。只顯示啟用中的產品；同一案件已選的產品不可重複選取。找不到時仍可手動輸入。
- **產品主檔管理**（系統管理員）：上傳完整產品 Excel（產品代碼、品名、規格）→ 先預覽差異（新增、更新、不變、重新啟用、預計停用、錯誤）→ 確認後一次同步。未列於 Excel 的產品改為停用，不刪除。預計停用超過 10% 時須額外確認；檔案有錯誤時不能同步。
- 已送出案件保存送出當時的產品資料，產品主檔更新不會改變歷史案件。
- 雙層審核流程、帳號角色、LINE 測試模式（Mock）均不變。

## V5.8 版本說明

LINE 尚未正式啟用。首次正式送件及首次登記發行成功後，通知區顯示「LINE 測試模式（Mock）」。模擬傳送只記錄測試時間，手動複製只將通知文字寫入剪貼簿。兩項操作均不傳送 LINE 訊息或圖面。

## 使用方式
- 網址：https://jryang-web.github.io/sucoot-drawing-approval/
- 以「員工編號＋密碼」登入；帳號由系統管理員建立，首次登入須修改密碼
- 忘記密碼請洽系統管理員重設

## 安裝到手機主畫面（PWA）
- **Android（Chrome）**：點頁尾「安裝 App」，或瀏覽器選單「⋮」→「安裝應用程式／加到主畫面」
- **iPhone／iPad**：必須用 **Safari** 開啟 → 點分享按鈕（方框加向上箭頭）→「加入主畫面」
- **LINE 內建瀏覽器**無法安裝：請點右上角「⋯」→「以預設瀏覽器開啟」後再安裝
- 系統更新時，畫面上方會出現「系統有新版本 → 立即更新」
- 資料一律即時從伺服器讀取；離線時可開啟畫面，但無法讀取或送出資料

## 流程
1. 申請人建立申請（可多筆圖號）並送出 → **第一層待審**
2. 所屬部門主管核准 → **第二層待審**（可退回、拒絕、調降急件）
3. 圖管主管核准 → **待發行**（第一層與第二層不可為同一人）
4. 圖管人員認領 → 核對圖面 → 登記發行 → **待簽收**
5. 申請人確認整案收到 → **已完成**；簽收前可回報整案異常
6. 發行後三個工作日（週一至週五，不含發行當天）未簽收，標記「簽收逾期」

## 角色
一般員工（EMPLOYEE，所有人都有）、部門主管（DEPT_MANAGER＋管轄部門）、圖管主管（DRAWING_MANAGER）、圖管人員（DRAWING_STAFF）、系統管理員（SYS_ADMIN）。
部門、員工帳號、角色、管轄與代理，全部由系統管理員在系統內設定。
