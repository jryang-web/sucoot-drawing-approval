## 1. Excel 原始資料驗證（`產品編碼對照表(2).xlsx`）

以原始 XML 解析（不經 Excel 函式庫轉換）：

| 項目 | 結果 |
|---|---|
| 工作表 | 1 個「產品編碼對照表」，範圍 A1:C7005，無合併儲存格 |
| 欄名 | 產品代碼、品名、規格 |
| 資料列 | **7,004** |
| 儲存格型別 | 21,015 格全部為文字（共用字串），**無數值格式**，不存在前導零被移除的風險 |
| 產品代碼 | 空白 0、前後空白 0、完全重複 0；長度 7–20；**17 組僅大小寫不同**（經逐組核對為不同產品，例如左／右、含舌片／切角） |
| 品名 | 空白 0、前後空白 1 筆（匯入時清除）、內部連續空白 100 筆（保留原樣） |
| 規格 | 空白 447 筆（允許）、前後空白 5,060 筆（匯入時清除） |
| 同名不同規格 | 917 個品名對應多個規格；107 組品名＋規格相同但編碼不同（搜尋結果一律顯示編碼區分） |
| **與 V5.8 編碼規則相容性** | **10 筆不相容**：8 筆含 `×`（例如 `GB-75-B-150-55×2-B`）、2 筆含 `"`（例如 `H7-CO5802"-5`） |

**相容性處理（最小影響）**：`write_r8_application` 的編碼檢查改為「符合 V5.8 規則 **或** 存在於產品主檔」。手動輸入仍完全沿用 V5.8 規則；資料庫產品主檔接受 1–30 個不含空白與控制字元的字元。

**全量匯入結果**：經管理員介面上傳後，資料庫 7,004 筆與 Excel 原文逐筆比對——缺少 0、多出 0、品名／規格不符 0、亂碼 0；**產品代碼 7,004/7,004 與 Excel 原文完全相同**。預覽 0.12 秒、正式同步 0.3 秒。
